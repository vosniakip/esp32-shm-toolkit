# Demonstração com sinais gerados localmente

Na pasta do pacote, com as dependências instaladas, gere os sinais artificiais e rode o roteiro:

```bash
python ferramentas/gerar_exemplos.py
python ferramentas/executar_demonstracao.py
```

O primeiro comando grava os sinais em `exemplos/sintetico/`. O segundo executa as análises e guarda as saídas em `exemplos/resultados/`.
